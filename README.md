# 👻 Haunted Terminal

A ghost that haunts your terminal using open-source AI. Built with React, TypeScript, and Ollama.

## 🎯 What is this?

The Haunted Terminal is a background daemon that watches your shell commands and occasionally responds with eerie, poetic commentary from a spirit that knows a little too much about what you're doing.
